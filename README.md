# CSE5114_Project
To run the project, follow these steps:
1. Clone the repository:
   ```
   git clone
    ```
2. Navigate to the project directory:

    ```
    cd CSE5114_Project
    ```
3. Build and start the Docker containers using Docker Compose:
    ```
    docker-compose up -d
4. Access the Airflow web interface by navigating to `http://localhost:8081` in your web browser.
5. Monitor the Spark application UI at `http://localhost:4041`.
6. To stop the Docker containers, run:
    ```
    docker-compose down
    ```
